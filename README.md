# MaqueenLab demo

[Open the interactive demo](https://dstiv-ai.github.io/maqueenlab-demo/)

A robot-car coding course for Years 7–8. Explore a lesson, change a program,
watch simulated sensor feedback, record a drive, and try hint-first Code Mate.
No account or robot is needed.

This repository contains only the built static demo. Robot movement and sensors
are simulated. Code Mate uses local scripted hints and makes no AI requests.
The demo contains fictional activities, with no student or school data.
